# Проект DataForge.

## Цель проекта:

### ***Подготовка клиентских данных для отображения в банковском виджете.***

**Инструкция по установке:**

Для работы проекта требуется [Poetry](https://python-poetry.org/).

    1. Клонируйте репозиторий:
      git clone https://github.com](https://github.com/burmspb-code/Homework_10_1.git
        cd project
    2. Установите зависимости:
        poetry install
    3. Запустите проект:
        poetry run python src/processing.py

## 🧪 Тестирование:

Для проверки корректности работы модулей DataForge используется фреймворк pytest.
Тесты покрывают основные функции маскировки, фильтрации и обработки данных.

Проверяемые области
create_masks — гибкая настройка масок для любых строк.
masks — корректность маскировки номеров карт и счетов.
widget — преобразование форматов дат и типов входных данных.
processing — логика фильтрации транзакций по статусу и сортировки по дате.
generators - модуль для работы с массивами транзакций на основе генераторов.
decorators - модуль для размещения декораторов.

После запуска pytest --cov-report html подробный отчет доступен в папке htmlcov/index.html

**Используемые модули:**

    - create_masks
    - masks
    - widget
    - processing

### **create_masks**

Модуль содержит функции обработки данных:

    - get_mask (принимает на вход строку и возвращает ее маску по заданным параметрам).
    Параметры, которые передаются в функцию:
        - string_input - входная строка
        - index_start - начальный индекс маски (отсчет от 0)
        - index_final - конечный индекс маски (отсчет от 0)
        - simbol_replace - символ для маски
        - index_separator - количество знаков, после которого будет поставлен разделитель
        - symbol_separator - символ для разделителя

### **masks**

Модуль содержит функции обработки данных:

    - get_mask_card_number (принимает на вход номер карты и возвращает его маску. Номер карты замаскирован и отображается в формате XXXX XX** **** XXXX,
    где X — это цифра номера. То есть видны первые 6 цифр и последние 4 цифры, остальные символы отображаются звездочками, номер разбит по блокам по 4 цифры,
    разделенным пробелами.
        Пример работы функции:
            7000792289606361     # входной аргумент
            7000 79** **** 6361  # выход функции
    - get_mask_account (принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и отображается в формате **XXXX,
    где X — это цифра номера. То есть видны только последние 4 цифры номера, а перед ними — две звездочки.
        Пример работы функции:
            73654108430135874305  # входной аргумент
            **4305  # выход функции

### **widget**

Модуль содержит функции обработки данных:

    - mask_account_card (принимает один аргумент — строку, содержащую тип и номер карты или счета и возвращать строку с замаскированным номером).
    - get_date (принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой в формате "ДД.ММ.ГГГГ").

### **processing**

Модуль содержит функции обработки данных:

    - filter_by_state (принимает список словарей и опционально значение для ключа state, по умолчанию 'EXECUTED',
    функция возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению).
    - sort_by_date (принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание),
    функция должна возвращать новый список, отсортированный по дате (date).

### **generators**

Модуль содержит функции обработки данных:

    - filter_by_currency (принимает на вход список словарей, представляющих транзакции и возвращает итератор,
    который поочередно выдает транзакции, где валюта операции соответствует заданной,
    что позволяет эффективно работать с большими объемами данных).

        Пример работы:
     
        usd_transactions = filter_by_currency(transactions, "USD")
        for _ in range(2):
            print(next(usd_transactions))

## Логирование

В проект добавлен декоратор `@log`, который автоматически фиксирует работу функций.

### Возможности

- **Отслеживание этапов**: логирует старт, успешное завершение или возникшую ошибку.
- **Гибкий вывод**: поддерживает запись как в консоль, так и в файл.
- **Детальные отчеты об ошибках**: при возникновении исключения логирует тип ошибки и входные данные (`args`, `kwargs`),
  после чего пробрасывает исключение дальше.

### Примеры использования

#### 1. Логирование в консоль

Если `filename` не указан, логи выводятся в консоль:

```python
from src.decorators import log

@log(filename=None)
def my_function(x, y):
    return x + y
```

#### 2. Логирование в файл

```python
@log(filename="mylog.log")
def my_function(x, y):
    return x * y
```
